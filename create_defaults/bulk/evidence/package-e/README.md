# Package E evidence map

These records preserve observed validation and artifact identities. They do not
approve uninspected artwork or authorize publication. The report is
[PACKAGE_E_REPORT.md](../../../PACKAGE_E_REPORT.md); bounded commands and prerequisites
are in [PACKAGE_E_USAGE.md](../../../PACKAGE_E_USAGE.md).

- `catalog-reconciliation.json`: all 21 categories, corrected capture, public/private
  paths and source/runtime identities.
- `language-audit.json`: fresh pinned 14-language / 139,398-contract coverage,
  source consistency, contributor and fitting-group digests.
- `snapshot-scope-consistency.json`: all 14 single/Based scope comparisons, full
  French/Arabic identity comparisons and actual strict/partial behavior.
- `fitting-proposals.json`: six exact unapproved preview contexts plus Arabic
  candidate/license/probe identities; no production font installation.
- `poster-benchmarks-and-historical-overlay.json`: all 18 poster scaling observations,
  five isolated legacy comparisons and explicitly historical pre-ICC overlay timings.
- `warm-profiling.json`: paired observations with unchanged content verification.
- `overlay-icc-defect.json`: source-mode risk inventory, original incorrect metrics
  and corrected 38-output comparisons; earlier Package D records remain unchanged.
- `overlay-profile-risk.json`: 64 additional mode/profile risk comparisons, exact
  renderer/policy/image identities and measured legacy differences, no acceptance.
- `pending-overlay-review.json`: existing review-service batch with exact membership,
  empty inspected subset and zero approval events; all 64 remain pending.
- `windows-linux.json`: final executable CI/source distinction, byte/pixel comparisons
  and separate platform artifact identities.
- `regression-tests.json`: exact final Windows outcomes, Linux CI link, skip reasons,
  focused regression identities and retained before-fix reproduction failures.
- `dependencies.json` and `dependency-alert-reconciliation.json`: pinned/native
  provenance, compatibility trial, original screen and its normalized/repository
  alert reconciliation. The latter supersedes the original mixed-case query coverage.

JSON envelope `sha256` values hash canonical JSON excluding that field; they are not
raw text-file hashes and are independent of Git line-ending normalization. Image
SHA-256 values always identify exact image bytes. Runtime/source/font/layout and
validation identities are preserved separately from decoded-pixel comparisons.

Full-run identity ledgers and final summaries are added only after complete verified
runs. Images, fonts, full local workspaces, databases and full benchmark output
collections stay in ignored local roots. These records must not be rewritten to
fabricate individual inspection, broaden old acceptance or conceal failed attempts.

The original `language-audit.json`, `snapshot-scope-consistency.json` and
`fitting-proposals.json` are immutable historical observations under the original
fitting rule. Their English-matching blockers do not define corrected current
eligibility. The multilingual addendum report and separate new evidence provide the
controlled before/after assessment without rewriting those records.

- `full-overlays.json`: all 4,122 corrected transforms verified; the finite initial
  attempt, single bounded resume and zero-render warm phase are reported separately.
- `overlay-output-identities.json.gz` and `overlay-ledger-index.json`: every exact
  source/transform/image/receipt/validation identity, with reconstructable manifest.
- `overlay-grayscale-alpha-verification.json`: all 460 grayscale ICC variants
  rechecked with zero lost-alpha outputs.
- `overlay-retained-before-after.json.gz` and `overlay-correction-impact.json`:
  3,571 retained outputs compared, 387 expected grayscale ICC changes and 3,184
  unchanged other modes; no approval is transferred.

- `multilingual-correction.json`: the controlled corrected 139,398-variant audit
  against the same pinned snapshot; three independent readiness dimensions, exact
  historical-acceptance context comparisons and separate captionless-artwork counts.
- `multilingual-poster-keys.json.gz`: only 960 poster-required keys per language,
  with exact valid/missing/invalid values, affected IDs, sources and English references.
- `multilingual-measurement-groups.json.gz`: exact native metrics and unactivated
  fitting proposals for 14,508 current-input groups and their 74,209 variant members.
- `multilingual-variant-index.json.gz`: every current variant validation/status and
  measurement binding. The complete raw 26.7 MB ledger remains local by exact hash;
  repeated catalog/source metadata is not duplicated in this compact index.
- `multilingual-validation.json`: current Windows/Linux regressions and exact
  sample comparisons, retained pre-correction failures and source/version identities.
  These records grant no artwork approval or typography activation.
